# Quizzy

Quizzy is a quiz application made up of:

- `app/` — Android client
- `quizzy-backend/` — backend service
- `Documentation/` — project documentation and diagrams

## Getting Started

See the `Documentation/` folder for user stories and diagrams. To build the Android app or backend service, use the Gradle/Maven wrappers included in their respective directories (`gradlew`, `mvnw`).
